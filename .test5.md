# Phase 4 Verification Tests (Rotate PDF)

Please perform these manual verifications to ensure the Rotate PDF feature is stable, accurate, and memory-safe:

1. **Single File Queue Test**: Drop multiple PDF files into the Dropzone. Verify that the queue resets and keeps only the first valid PDF.
2. **90° Clockwise Rotation**: Upload a PDF, select `90° Right`, click "Rotate PDF", and download `rotated-YYYY-MM-DD.pdf`. Open the resulting file and verify all pages are turned 90° clockwise.
3. **180° Flip Rotation**: Upload a PDF, select `180° Flip`, process, and check that the downloaded PDF pages are turned upside down.
4. **90° Counter-Clockwise (270°)**: Upload a PDF, select `90° Left`, process, and verify all pages are rotated 270° (or 90° counter-clockwise).
5. **Cumulative Rotation**: Upload a PDF that was already rotated 90° previously. Rotate it another 90° clockwise. Verify the result is rotated 180° relative to the original.
6. **Non-PDF Validation**: Attempt to drag and drop an image or text file. Verify it is rejected immediately with a friendly validation error.
7. **Corrupted File Graceful Handling**: Attempt to upload a password-protected or corrupted file. Verify that a clear error message is displayed ("Failed to read...") without crashing the application.
8. **Cancellation & Memory Cleanup**: Click Rotate on a larger file and cancel midway. Verify that the worker terminates cleanly and the file state returns to idle.
