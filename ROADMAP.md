# Roadmap

## Phase 1: Foundation (Current)
- [x] Project initialization (React, Vite, TS, Tailwind v4).
- [x] Tooling setup (ESLint, Prettier, Husky, Vitest, Playwright).
- [x] Core folder structure & path aliases.
- [x] Routing & Global Layout.
- [x] Homepage & core documentation.

## Phase 2: Shared File System
- Drag & Drop interface.
- File validation (Zod).
- Upload queue and preview generation.
- Blob lifecycle & Web Worker infrastructure.

## Phase 3: MVP Tool - Merge PDF
- Client-side PDF merging with `pdf-lib`.
- Drag-to-reorder UI.
- Memory-safe processing.

## Phase 4: Remaining PDF Tools (Tier 1 & Tier 2)
- Split PDF, Rotate PDF, Extract Pages, Delete Pages, Page Numbers.
- Images to PDF.
- Unlock & Protect PDF (Tier 3).

## Phase 5: Image Tools (Tier 1)
- Resize Image, Compress Image.
- Crop, Rotate, Convert, Remove Metadata.
- Batch Processing support.

## Phase 6: Polish & Deploy
- Bundle optimization & lazy loading.
- Lighthouse > 95 target.
- CI/CD Deployment.

## Stretch Goals (Future Work)
- OCR (Optical Character Recognition)
- Watermarks & Annotations
- Redaction
- Digital Signatures
