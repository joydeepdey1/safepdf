# Phase 3 Verification Tests (Merge PDF)

Please perform these manual verifications to ensure Phase 3 (Merge PDF) is stable and robust:

1. **Basic Merge**: Upload 2 PDFs and merge them. Verify the output contains all pages in the correct order.
2. **Stress Test**: Upload 10+ PDFs and merge them.
3. **Differing Formats**: Upload PDFs with different page sizes (e.g., A4 and Letter). Verify they merge successfully.
4. **Large File Test**: Upload a large PDF (>50MB). Monitor browser memory to ensure it doesn't crash, and check that the resulting file downloads correctly.
5. **Validation Test**: Attempt to upload an image or text file. Verify it is rejected by Zod validation before entering the queue.
6. **Corruption Handling**: Add a password-protected or corrupted PDF to the queue alongside a valid PDF. Attempt to merge. Verify that a graceful error message appears ("Failed to read [filename]...") and the app does not crash.
7. **Memory Cleanup**: Add several large PDFs, merge them, download the result, and then click "Clear all" or remove them individually. Verify in your browser's task manager that memory drops back down, indicating Object URLs and ArrayBuffers were successfully garbage collected.
8. **UI Responsiveness**: Verify the progress indicator updates smoothly during the merge and the layout remains usable on mobile viewports.
