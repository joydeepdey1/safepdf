# Phase 5 Verification Tests (Image Tools: Resize & Compress)

Please perform these manual verifications to ensure Phase 5 tools function properly:

## A. Resize Image (`/image/resize`)
1. **Scale by Percentage**: Upload an image, choose **50%**, click "Resize Image". Open the downloaded image and verify pixel width and height are 50% of the original.
2. **Resize by Width/Height (Aspect Ratio Locked)**: Upload an image with width 2000px and height 1000px. Set width to **800px** with "Maintain aspect ratio" enabled. Verify the downloaded image has dimensions 800×400px.
3. **Batch Resize**: Drop 3-4 images at once. Resize by 25%. Verify all images download with prefix `resized-` and reduced dimensions.

## B. Compress Image (`/image/compress`)
1. **Balanced Compression (Recommended 70%)**: Upload a large JPEG/PNG (e.g. 3MB). Compress with Balanced mode. Verify the UI reports savings (e.g. "Saved ~60-70%") and the downloaded image size is significantly smaller.
2. **Max Compression (50%)**: Test Max Compression on a high-resolution photo. Verify substantial file size savings.
3. **Custom Slider**: Switch to custom slider, set quality to 30%, and compress.
4. **Batch Compress**: Upload 5 images simultaneously. Verify progress bar advances smoothly and all compressed files download properly.

## C. Shared Checks
- **Non-Image Rejection**: Drop a PDF or text file into either tool and verify it is rejected with a validation error.
- **Cancellation**: Start batch processing and click Cancel. Verify the worker terminates cleanly and the file queue resets to idle.
