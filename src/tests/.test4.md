# Phase 4 Verification Tests (Split PDF)

Please perform these manual verifications to ensure the Split PDF feature is stable and robust:

1. **Queue Limit Test**: Attempt to drop multiple PDFs into the Dropzone. Verify that the queue clears and only accepts the first valid file.
2. **Invalid Range Format**: Enter invalid formats like `abc`, `1-`, or `-5`. Verify that an immediate validation error prevents processing.
3. **Out of Bounds Test**: Enter a range that exceeds the document's page count (e.g., `1-999` for a 10-page document). Verify the worker catches this and displays a graceful error ("End page (999) is out of bounds...").
4. **Reversed Range Test**: Enter `5-1`. Verify validation catches this error ("Start page cannot be greater than end page").
5. **Basic Extraction**: Enter a valid range (e.g., `2-4`), process, and download. Verify the downloaded PDF contains exactly 3 pages, corresponding to pages 2, 3, and 4 of the original document.
6. **Corruption Handling**: Upload a corrupted or password-protected PDF. Verify the worker catches the error gracefully on `PDFDocument.load()`.
