# Phase 4 Verification Tests (Delete Pages)

Please perform these manual verifications to ensure the Delete Pages feature functions properly:

1. **Single Page Deletion**: Upload a 5-page PDF, enter `3`, and click "Delete Pages". Download `deleted-pages-YYYY-MM-DD.pdf` and verify it contains 4 pages (pages 1, 2, 4, and 5 of the original).
2. **Page Range Deletion**: Upload a 10-page PDF, enter `4-7`, process, and verify that the resulting PDF contains 6 pages (original pages 1-3 and 8-10).
3. **Mixed Page List & Range**: Upload a 10-page PDF, enter `1, 3, 6-8, 10`. Verify the resulting PDF contains exactly pages 2, 4, 5, and 9.
4. **All Pages Deletion Prevention**: Attempt to delete all pages (e.g. `1-5` on a 5-page document). Verify the worker returns an error ("Cannot delete all pages. The resulting document must have at least 1 page.") and does not crash.
5. **Out of Bounds Check**: Enter `99` on a 5-page PDF. Verify the worker returns an error ("Page 99 is out of bounds...").
6. **Syntax Error Validation**: Enter invalid text like `abc` or `5-2`. Verify UI validation displays an error before starting the worker.
7. **Single File Queue Constraint**: Drop 3 files at once. Verify only the first valid PDF is kept in the queue.
8. **Cancellation & Memory Cleanup**: Start processing a large file and cancel. Verify worker terminates cleanly and memory is reclaimed.
